Sales AI Assistant — RAG для отдела продажFeatured

/01
Задача

Отдел продаж тратит часы на поиск информации по разрозненным документам и CRM, чтобы ответить клиенту — ответы медленные и противоречивые.

Решение

Полностью локальный RAG-ассистент: FastAPI + async SQLAlchemy 2.0 + PostgreSQL с pgvector. Документы чанкуются и эмбеддятся (e5-large, 1024 dim); запрос проходит через векторный поиск, реранкинг и локальную Qwen 2.5 Coder 14B (LM Studio) с трассировкой источников.CI на GitHub Actions (Ruff + Mypy + Pytest),

86% покрытие тестами · 22 unit-теста · 100% локально, без внешних API

Автоматический генератор карточек товаров

/02
Задача

Создание одной карточки товара занимало около часа и требовало дизайнера для каждого нового продукта.

Решение

Автономный n8n-пайплайн: читает данные товара, локальная LLM пишет детальный промпт для генерации изображения из названия товара, ComfyUI (JuggernautXL) рендерит карточку, результат сохраняется в Google Drive. Система творчески адаптируется к вводу — например, сгенерировала концепт «New Balance» из исходного файла Nike.

~1 час ручной работы → ~2 минуты на карточку
  • n8n
  • ComfyUI
  • JuggernautXL
  • LM Studio
  • Google Drive API

Автономный AI-агент для соцсетей

/03
Задача

Маркетинговые команды тратят часы на идеи и дизайн для каждой кампании.

Решение

n8n-агент, который превращает одну тему в готовую визуальную серию для публикации. Локальная LLM (Phi-4 14B) пишет подписи, а фиксированный набор брендовых шаблонов в ComfyUI держит единый стиль. SplitInBatches генерирует всю серию за один запуск — например, полную кампанию «свежевыжатый апельсиновый сок» из одного ввода.

Одна тема → полная визуальная серия за один запуск
  • n8n
  • ComfyUI
  • Phi-4 14B
  • SplitInBatches

Автономный документо-пайплайн (ADPP)

/05
Задача

Ручное извлечение данных из инвойсов и PDF занимает часы и подвержено ошибкам.

Решение

Full-stack пайплайн, работающий полностью локально: FastAPI принимает документы, Tesseract OCR извлекает текст, локальная LLM (через LM Studio) парсит структурированные поля (номер инвойса, дата, поставщик, сумма), результаты сохраняются в SQLite и отображаются в дашборде Streamlit. Без облака, без лимитов на документ.

15 минут → менее 30 секунд на инвойс
  • Python
  • FastAPI
  • Tesseract OCR
  • LM Studio
  • SQLite
  • Streamlit
  • Docker

архитектура пайплайна — только локально, без облака
