Automated E-Commerce Product Card Generator

/01
Problem

Creating a product card took about an hour per item and required a designer for every new product.

Solution

An autonomous n8n pipeline: it reads product data, a local LLM writes a detailed image-generation prompt from the product name, ComfyUI (JuggernautXL) renders the card, and the result is saved to Google Drive. The system adapts creatively to the input — for example, it generated a “New Balance” concept from a Nike source file.

~1 hour of manual work → ~2 minutes per card
  • n8n
  • ComfyUI
  • JuggernautXL
  • LM Studio
  • Google Drive API

Autonomous AI Social Media Agent

/02
Problem

Marketing teams spend hours on ideation and design for every single campaign.

Solution

An n8n agent that turns one topic into a ready-to-post visual series. A local LLM (Phi-4 14B) writes the captions, while a fixed set of brand templates in ComfyUI keeps every visual on-style. SplitInBatches generates the whole series in one run — e.g. a complete “orange fresh juice” campaign from a single input.

One topic → a full visual series in a single run
  • n8n
  • ComfyUI
  • Phi-4 14B
  • SplitInBatches

Autonomous Document Processing Pipeline (ADPP)

/04
Problem

Manually extracting data from invoices and PDFs takes hours and is error-prone.

Solution

A full-stack, 100% local pipeline: FastAPI receives documents, Tesseract OCR extracts the text, a local LLM (via LM Studio) parses structured fields (invoice number, date, vendor, total), results are stored in SQLite and visualized in a Streamlit dashboard. No cloud, no per-document limits.

15 minutes → under 30 seconds per invoice
  • Python
  • FastAPI
  • Tesseract OCR
  • LM Studio
  • SQLite
  • Streamlit
  • Docker
