01

Sales AI Assistant — RAG для отдела продажИзбранное

Отдел продаж тратит часы на поиск информации по разрозненным документам и CRM, чтобы ответить клиенту — ответы медленные и противоречивые.

Полностью локальный RAG-ассистент: FastAPI + async SQLAlchemy 2.0 + PostgreSQL с pgvector. Документы чанкуются и эмбеддятся (e5-large, 1024 dim); запрос проходит через векторный поиск, реранкинг и локальную Qwen 2.5 Coder 14B (LM Studio) с трассировкой источников. CI на GitHub Actions (Ruff + Mypy + Pytest), развёртывание в Docker.

Retrieval hit rate 0.95 · semantic similarity 0.97 (golden set из 20 вопросов) · 22 теста, покрытие 86% · 100% локально, без внешних API

Python · FastAPI · PostgreSQL · pgvector · Qwen 2.5 Coder · Docker · GitHub Actions · pytest

чанкинг → embeddings → векторный поиск → реранкинг → ответ с источниками

02

Автоматический генератор карточек товаров

Создание одной карточки товара занимало около часа и требовало дизайнера для каждого нового продукта.

Автономный n8n-пайплайн: читает данные товара, локальная LLM пишет детальный промпт для генерации изображения из названия товара, ComfyUI (JuggernautXL) рендерит карточку, результат сохраняется в Google Drive. Система адаптируется к вводу — например, сгенерировала концепт «New Balance» из исходного файла Nike.

~1 час ручной работы → ~2 минуты на карточку

n8n · ComfyUI · JuggernautXL · LM Studio · Google Drive API

03

Автономный AI-агент для соцсетей

Маркетинговые команды тратят часы на идеи и дизайн для каждой кампании.

n8n-агент, который превращает одну тему в готовую визуальную серию для публикации. Локальная LLM (Phi-4 14B) пишет подписи, фиксированный набор брендовых шаблонов в ComfyUI держит единый стиль. 05

Автономный документо-пайплайн (ADPP)

Ручное извлечение данных из инвойсов и PDF занимает часы и подвержено ошибкам.

Full-stack пайплайн, работающий полностью локально: FastAPI принимает документы, Tesseract OCR извлекает текст, локальная LLM (через LM Studio) парсит структурированные поля (номер инвойса, дата, поставщик, сумма), результаты сохраняются в SQLite и отображаются в дашборде Streamlit. Без облака, без лимитов на документ.

15 минут → менее 30 секунд на инвойс

Python · FastAPI · Tesseract OCR · LM Studio · SQLite · Streamlit · Docker

архитектура пайплайна — полностью локально, без облака
